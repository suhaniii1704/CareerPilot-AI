# CareerPilot AI

## Your Personalized AI Career Coach

CareerPilot AI is an AI-powered career guidance platform that helps students improve their resumes, prepare for interviews, analyze job descriptions, and receive personalized career recommendations using Generative AI.

## Features

- Resume Upload
- Resume Analysis
- Resume Chat (RAG)
- Interview Coach
- Job Match
- Career Advisor

## Tech Stack

- Python
- Streamlit
- Grok API
- LangChain
- FAISS
- CrewAI
- Whisper
- Edge TTS
